# Правила работы с репозиторием 

1. Main — только для стабильных версий. Прямые коммиты запрещены.
2. Develop — основная ветка для интеграции кода.
3. Feature-ветки — для каждой новой задачи создается отдельная ветка от develop.
    Такие примеры как: CreateModels, CreateDB, AddAuth.
4. Процесс работы:
   Создать ветку от develop.
   Выполнить задачу.
   Сделать Pull Request (PR) обратно в develop.
   После проверки (Code Review) — Merge в develop.
