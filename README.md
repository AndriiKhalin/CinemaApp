# Cinema Booking System (MVP)

Welcome to the project!

## Project Structure
* 📁 **backend-api**: The C# ASP.NET Core API and SQLite Database.
* 📁 **frontend-web**: The HTML/JS website.
* 📁 **frontend-maui**: The desktop/mobile application in C#.
* 📁 **scripts**: Python scripts to fill our database with movies.
* 📁 **docs**: Project requirements and screenshots.

## How to start
1. Clone this repository: `git clone https://github.com/AndriiKhalin/CinemaApp.git`
2. Go to your assigned folder.
3. Read the comments in your files to see your tasks!
